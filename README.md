# Rubik's Cube Academy India — website

Single-page static site. `index.html` is the whole site; images live in `images/`.

Hosting: Cloudflare Pages (connected to this repo). Every push to `main` updates the live site.

Things to fill in inside `index.html`:
- `data-yt=""` on the two video blocks → paste the YouTube video ID
- `data-deadline=""` on the countdown → scholarship closing date, e.g. `2026-11-06T23:59:00+05:30`
- `wa.me/910000000000` → Divya's WhatsApp number
- `[4.9]` / `[N]` → real Google rating and review count
- Photo placeholders (dashed boxes) → real images from `images/`
